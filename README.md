# HRReserveApp (WinForms, C#)

Дипломное приложение для общеобразовательного учреждения:

- авторизация сотрудников кадровой службы;
- ведение кадрового резерва;
- сопровождение аттестационных процедур;
- сводная аналитика по состоянию резерва и аттестаций.

## Технологии

- .NET 8
- Windows Forms
- Локальное хранение данных в JSON (`%LocalAppData%/HRReserveDiploma/app-data.json`)

## Быстрый старт

1. Откройте `HRReserveApp/HRReserveApp.csproj` в Visual Studio 2022+.
2. Запустите проект.
3. Авторизуйтесь:
   - логин: `admin`
   - пароль: `admin123`

## Функциональность

### 1. Авторизация
- проверка логина и пароля;
- блокировка входа при неверных данных.

### 2. Кадровый резерв
- добавление, редактирование, удаление кандидатов;
- хранение ФИО, должности, подразделения, стажа, уровня компетенций и плана развития.

### 3. Аттестации
- назначение аттестации на сотрудника;
- ведение статуса (запланирована / в процессе / завершена);
- фиксация результата и комментариев комиссии.

### 4. Аналитика
- общий размер кадрового резерва;
- количество активных и завершённых аттестаций;
- число рекомендованных к повышению.
