# HRReserveApp (WinForms, C#)

Полноценное дипломное приложение для общеобразовательного учреждения:

- формирование кадрового резерва;
- сопровождение аттестационных процедур;
- аналитическая панель с контрольными индикаторами;
- генерация отчётов (TXT + CSV).

## Ключевые возможности

### 1) Авторизация
- вход по логину/паролю;
- стартовая роль кадрового специалиста.

### 2) Современный интерфейс
- переработанный визуальный стиль (карточки KPI, актуальная цветовая палитра, рабочие вкладки);
- панель управления с индикаторами: резерв, активные аттестации, рекомендованные, просроченные;
- блок уведомлений о ближайших и просроченных аттестациях.

### 3) Кадровый резерв
- CRUD для кандидатов;
- фильтрация по уровню компетенций;
- поиск по ФИО, должности и подразделению.

### 4) Аттестации
- CRUD для аттестационных записей;
- быстрый сценарий завершения аттестации;
- хранение статуса, результата и комментария комиссии.

### 5) Отчётность (для диплома)
- сводный аналитический отчёт (`.txt`);
- выгрузка кадрового резерва (`.csv`);
- выгрузка аттестаций (`.csv`);
- автоматическое сохранение в `Документы/HRReserveReports`.

## Технологии

- .NET 8 (`net8.0-windows`)
- Windows Forms
- JSON-хранилище: `%LocalAppData%/HRReserveDiploma/app-data.json`
